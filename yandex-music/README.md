Все сделано с помощью вот [этой](https://yandex-music.readthedocs.io/en/main/index.html) библиотеки.

Если не хочется авторизовываться через основной аккаунт для получения ключа, можно сделать это через второй аккаунт.
На втором аккаунте придется добавить все треки в избранное, тогда можно будет использовать ключ от второго аккаунта.


Для запуска:

- Установить зависимости

```
bash
python3 -m venv venv \
source ./venv/bin/activate \
pip install -r requirements.txt
```

- Создать файл для логов

```
bash
touch out.log
```

- Запустить

```
python
python3 -u main.py >> out.log
```

- Отслеживать прогресс

```
bash
tail -f out.log
```


Если скачивание оборвется на определенном треке, можно в переменную `start_from` выставить последний 100% скачанный трек и начать качать только новые треки.

Чтобы проверить в каком качестве скачался трек, можно запустить
```
bash
python3 quality-info.py
```
